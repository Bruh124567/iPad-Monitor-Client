# iPad Monitor Client
Client for iPad Monitor. It lets you use your iPad as a second monitor for your Windows PC and stuff

## Very early in development, there are (many) bugs, and the host is coming soon! And it’s probably going to be rebranded sometime because the current name is pretty bad but yeah at least the client works
 
# Build instructions

1. Open the thing in Xcode
2. Build it
3. it runs (I hope)
